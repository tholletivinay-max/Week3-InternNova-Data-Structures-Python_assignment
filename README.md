# Week 3: Data Structures in Python

## About the Project

This project is part of my Week 3 internship assignment on Data Structures in Python. It demonstrates how Python data structures can be used to store, access, modify, and manage data.

## Objectives

- Understand Python's basic data structures.
- Learn how to access and modify data.
- Practice commonly used Python methods.
- Perform operations on lists, tuples, sets, and dictionaries.

## Tasks Completed

### Task 1: Lists — 25 Marks
- Creating a list
- Accessing elements
- Adding elements
- Updating elements
- Removing elements
- Sorting a list

### Task 2: Tuples — 20 Marks
- Creating a tuple
- Accessing elements using indexing
- Tuple slicing
- Finding the length
- Basic tuple operations

### Task 3: Sets — 25 Marks
- Creating a set
- Removing duplicate values
- Adding and removing elements
- Union
- Intersection
- Difference

### Task 4: Dictionaries — 30 Marks
- Creating a student information dictionary
- Accessing values
- Adding new key-value pairs
- Updating values
- Removing data
- Displaying keys and values
- Using dictionary methods

## How to Run

1. Install Python 3.
2. Open this folder in Visual Studio Code.
3. Open the terminal.
4. Run the required program using:

```bash
python task1_lists.py
```

Replace `task1_lists.py` with the other Python filenames to run the remaining tasks.
